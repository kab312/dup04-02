Шаг 17

Development, build и deploy — не одно и то же

Разделите три ситуации по смыслу: разрабатываем, подготавливаем, размещаем.

Я меняю файлы и сразу проверяю их через localhost.
Инструмент подготовил файлы в папке dist.
Готовая версия размещена на хостинге и доступна пользователям.
Без перетаскивания: выбрать зоны
«Проверяю через localhost»
«Получил dist»
«Разместил на хостинге»

Development

Текущая разработка и быстрый локальный просмотр.

Build

Подготовка рабочей версии проекта.

Deploy

Размещение там, где проект доступен пользователям.

Сначала разделите действия по глаголам: разрабатываем → подготавливаем → размещаем.
Запустить локально ≠ подготовить build ≠ опубликовать.

Шаг 19

Что теперь находится у вас в голове?

Проект — центр работы. IDE, терминал, браузер и DevTools не идут одним конвейером: каждый инструмент решает свою задачу.

ИСХОДНИК
IDE↔Project files

IDE находит и изменяет исходные файлы проекта.

ЛОКАЛЬНЫЙ ЗАПУСК
Terminal→Dev server

Терминал запускает команду, dev server работает на компьютере.

ПРОВЕРКА
Browser↔DevTools

Браузер получает страницу через localhost, DevTools исследует состояние и запросы.

ПУБЛИКАЦИЯ
Build→Deploy

Сначала готовим рабочую версию, затем размещаем её для пользователей.
